# 레벨업과외 — 수업료 안내 · 선생님 소개 · 수업 진행 순서 페이지에 필요한 정보

네이버 비즈채널 "자체 콘텐츠 불충분 / 서비스 실체 확인 불가" 대응용 세 페이지를 만들기 전에 필요한 실제 정보입니다.
답을 주시면 그대로 페이지로 만듭니다. 모르는 항목은 "미정"이라고 적어 주셔도 됩니다.

## 1. 수업료 안내 (/pricing)

1. 수업료를 **정확한 금액**으로 공개할까요, **범위**(예: 월 30~40만 원)로 공개할까요?
2. 기준 단위는 무엇인가요? (월 단위 / 회당 / 시간당)
3. 학년별 금액 또는 범위
   - 초등 / 중등 / 고등 / 재수·N수 / 성인
4. 과목별 차이가 있나요? (예: 수학·영어 vs 국어·사회·과학, 코딩, 외국어 회화, 검정고시, 한글, 학습코칭)
5. 기본 수업 구성: 주 몇 회, 회당 몇 분인가요? (예: 주 2회 90분) 다른 구성을 고를 수 있나요?
6. **방문 수업**과 **화상 수업**의 수업료 차이가 있나요? 있다면 얼마나?
7. 선생님 경력·학력(일반 / 전문 / 특별 강사 등)에 따라 금액이 달라지나요?
8. 수업료 외 비용: 교재비, 교통비(원거리 방문), 레벨 진단비 등이 있나요?
9. **무료 체험수업** 조건: 30분 1회가 맞나요? 과목·지역 제한이 있나요?
10. 결제 방식과 시점: 선불/후불, 계좌이체/카드, 매월 며칠 기준인가요?
11. 환불·중도 해지 규정: 남은 횟수 환불 기준, 당일 취소·보강 규정
12. 형제 동시 등록, 장기 등록 할인 같은 혜택이 있나요?

## 2. 선생님 소개 (/teachers)

1. 소개할 선생님은 몇 분인가요? (3~6분 권장)
2. 선생님마다 아래 항목을 주세요. 실명 대신 **이니셜이나 성+선생님**(예: 김○○ 선생님)으로 표기합니다.
   - 담당 과목과 학년대
   - 경력 연차와 주요 경력(학원·과외·교직 등)
   - 학력: 공개 여부와 **증빙 가능 여부** (학력을 쓰려면 증빙이 있어야 합니다. "SKY 출신" 같은 표현은 증빙 없으면 뺍니다)
   - 수업 방식 한 줄 (예: 오답 노트 중심, 매주 테스트)
   - 수업 가능 지역(방문) / 화상 가능 여부
   - 사진 사용 여부 (없으면 일러스트나 이니셜 아이콘으로 대체)
3. 전체 선생님 수와 선발 기준: 어떤 과정을 거쳐 뽑나요? (서류 → 면접 → 시범수업 등)
4. 선생님 교체 규정: 학생과 맞지 않을 때 교체가 가능한가요? 횟수·조건은?
5. 선생님과 학생의 매칭 기준: 지역, 성별 선호, 성향 등 무엇을 고려하나요?

## 3. 수업 진행 순서 (/process)

1. 상담 신청 후 **첫 연락까지 걸리는 시간** (예: 영업일 기준 24시간 이내)
2. 상담 방식: 전화 / 카톡 / 방문 중 무엇으로 하나요? 상담 시간대는?
3. **레벨 진단**: 어떻게 하나요? (진단 테스트지, 30분 시범 수업 중 확인, 최근 성적표 확인 등) 비용은?
4. **선생님 매칭**까지 걸리는 시간과 매칭 후 학부모에게 알려 주는 정보(프로필 범위)
5. **체험수업**: 30분 무료가 맞나요? 체험 후 선생님 교체 요청이 가능한가요?
6. **정규수업 시작**: 계약서나 동의서를 쓰나요? 교재는 누가 정하나요?
7. 수업 중 관리: 수업 일지, 월간 리포트, 학부모 상담 주기가 있나요? 있다면 어떤 형식인가요?
8. 수업 시간 변경·보강 규정
9. 상담 가능 시간 (푸터의 "상담 시간" 줄에 넣을 값입니다. 예: 평일 10:00~21:00, 주말 10:00~18:00)

## 4. 후기 (선택)

- 메인의 학습후기 이미지 8장은 실제 후기인가요? 학년·과목·기간을 함께 적을 수 있나요?
- 지어낸 후기는 표시광고법 위반이므로, 실제 후기가 없으면 후기 섹션을 줄이거나 빼는 쪽을 권합니다.
